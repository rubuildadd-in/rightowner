# RightOwner (by Rubuild Services)

The RightOwner Microsoft Teams app. This repository is published with GitHub Pages at https://app.rubuild.com.

- `index.html`, `app.js`, `styles.css` — the app shown inside Teams
- `config.js` — the only file that needs editing (Microsoft Entra client ID)
- `redirect.html` — sign-in return page
- `lib/` — Microsoft's official Teams and sign-in libraries (unmodified)

Customer data is stored in a SharePoint list in each customer's own Microsoft 365 tenant. No server is involved.
